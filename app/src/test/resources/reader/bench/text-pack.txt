# Import benchmark — text-shaped documents with answer keys.
#
# Format:  "=== <file name>" starts a document (the extension decides how it is sniffed),
#          "--- expect" starts its answer key. In the key:
#            DAY <label>                    a training day (label is informational)
#            WEEK <n>                       following days belong to week n (default 1)
#            <exercise> | <sets> | <reps>   one exercise; reps as a person would write them:
#                                           "8", "8-12", "AMRAP", "30s", "40m", "12/10/8" (one per set)
#          Only the weeks listed are scored. Rest days are never listed.
#
# Every document is written the way a real coach / lifter / app writes programs, including the mess.
